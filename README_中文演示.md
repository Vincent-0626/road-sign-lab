# 路标识别实验室

基于 PyTorch 的交通标志分类与干扰评估 Demo。支持上传裁剪好的标志图片、展示前三个分类结果，并对比亮度、模糊和遮挡变化下的预测。

## 项目来源与本次工作

本项目以 https://github.com/tanmayai23/gtsrb-traffic-sign-recognition 为基础。原项目提供分类网络、数据预处理、训练和评估代码；其作者及 MIT 许可证保留在 LICENSE 文件中。

本次新增中文网页 Demo、镜像数据准备、确定性扰动评估，以及“每轮变化但可复现”的数据增强；在相同数据划分和参数下，与原项目的固定增强方案进行了单次对比。下文结果来自这次训练，不是原仓库的成绩。

## 数据与实验

GTSRB 共 43 类德国交通标志。原训练部分按物理标志的拍摄序列分组，划出训练集 31,379 张、验证集 7,830 张；独立测试集 12,630 张。训练和验证序列重合为 0。数据从保留原图、标注框和序列编号的公开镜像读取；数据文件不包含在仓库中。

两组均使用相同划分、随机种子 42、15 轮、批次 128，按验证集选择各自的最佳模型。每张测试图片在相同条件下分别评估；干扰施加在原图、模型预处理之前。

| 测试条件 | 原固定增强 | 逐轮变化增强 |
| --- | ---: | ---: |
| 原始图片 | 96.98% | 97.51% |
| 亮度 × 0.45 | 93.39% | 94.06% |
| 高斯模糊核 5 | 91.86% | 92.82% |
| 左侧局部遮挡（宽度参数 0.3） | 95.38% | 95.96% |

以上为准确率，来自一次单随机种子实验，不能证明改进对所有数据或道路场景都有效。本次训练的权重、训练历史和测试记录保存在 experiments/2026-11-18/；数据集不包含在仓库中。

## 运行

安装好依赖后，运行 python -m src.web_demo --port 7861 --checkpoint experiments/2026-11-18/varying_best.pt。默认不指定 checkpoint 时使用上游模型。服务只监听服务器的 127.0.0.1，远程使用时可通过 SSH 端口转发访问。

## 使用范围

输入应是已裁剪、主体为单个交通标志的图片。当前版本没有从完整道路画面中定位标志的模块，未在真实道路部署，不能用于驾驶决策。界面分数为模型 softmax 输出，不等同于经过校准的正确概率。
